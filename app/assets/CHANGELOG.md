# LocalShare 更新日志

## 0.2.1 — 2026-10-05

### 任务中心与传输

- 发送、接收、媒体同步和实际网页下载统一显示为任务，列表展示进度、速度、已用时间与预计剩余时间。
- 离开进度页或关闭任务详情后，传输继续进行；取消任务成为独立操作。
- 默认同时运行 2 个传输任务，其余排队，可在设置中调整为 1–8 个；媒体同步最多同时运行 1 个。
- 支持多个独立接收会话，普通接收为每个任务创建单独目录，保留文件原名及相对目录结构；媒体同步继续使用原有保存方式。
- 原生 LocalShare 传输新增暂停、继续与失败重试，持久化分块偏移，并验证分块和完整文件 SHA-256。
- 任务记录保存到本地，支持手动清除与按保留时间清理；暂停、中断、失败任务保留恢复信息。
- 媒体同步的接收校验和确认记录更新移入任务流程，离开备份页仍能完成确认。
- 网页分享服务在返回后保持运行，通过独立的停止操作结束；原生传输与网页传输可以同时进行。

### 首页与导航

- 主导航调整为「首页、任务、发送、同步、设置」，任务紧接首页。
- 首页优先展示发送文件、网页传输和媒体同步操作，并显示待确认接收、当前任务与附近设备。
- 网页传输明确区分发送和接收；设备 IP 与端口收纳到信息弹窗，首页可切换接收方式和打开接收目录。
- 接收请求统一由首页和任务页管理，旧接收历史仍可从任务页「接收文件」入口访问。
- 已完成文件可从任务详情直接打开或在文件夹中显示，优化窄屏和大字体布局。

### 维护与安装

- 仅保留英文、中文 README，清理失效文件和不适用于 LocalShare 的 WinGet 发布任务。
- 应用版本为 0.2.1，构建号 63；Windows 安装版本为 0.2.1.63。
- Android 正式安装包仅支持 arm64-v8a（ARM 64 位），Windows 继续提供 x64 安装程序与免安装包。
- Android 与 Windows Release 安装包沿用项目内固定签名证书，签名私钥和密码不上传 GitHub。
- 已安装本地签名版 0.2.0 的用户可覆盖升级。旧 GitHub 正式版 0.1.0 / 0.1.1 的 Android 签名不同，需先备份应用配置和记录，再卸载旧版安装新版；已保存的接收文件请另行妥善保留。
- Windows 使用自签名代码签名证书，系统仍可能显示发布者不受信任或 SmartScreen 提示。

### 支持范围

- 字节断点续传需要发送与接收双方使用支持新协议的 LocalShare；旧客户端继续使用整文件传输。
- Android content:// 系统目录和网页上传目前使用整文件方式；浏览器单文件下载支持 HTTP Range，ZIP 下载不支持续传。
- 当前支持应用运行期间切换页面继续任务；Android 息屏与系统后台保活留待后续版本，未承诺后台长期运行。

## 0.1.0（开发测试版）— 2026-07-13

### 主要功能

- 支持 Windows 与 Android 客户端在局域网内直接互传文件、文本和文件夹。
- 支持通过链接或二维码发送，接收端不需安装软件。
- 支持从浏览器向当前设备上传文件，仍经过接收确认流程。
- Android 支持手动扫描照片和视频，向指定电脑进行增量备份。
- 每台备份电脑使用独立档案；只有手动确认电脑已完整保存后，内容才会标记为已备份。

### 界面调整

- 主导航统一为“发送、接收、备份、设置”，启动后直接进入发送页。
- 发送页先选择内容，选择后按“附近设备、通过链接发送”的顺序展示。
- 接收页直接显示在线状态、实际保存目录、自动保存和网页接收入口。
- 手机备份成为独立主标签，扫描后先显示附近电脑，链接发送位于其下方。
- 精简 Windows 和 Android 的发送、接收、备份和设置页，统一 LocalShare 品牌与视觉风格。

### 问题修复

- 修复 Windows 和 Android 主页可能显示白屏的问题。
- 修复从链接发送页返回后，发送或备份按钮无法再次使用的问题。
- 修复取消等待中的客户端传输时，备份页可能长时间锁定的问题。
- 修复 Windows 默认接收目录可能缺少盘符，导致文件历史路径无法打开的问题。
- 优先读取 Windows 系统下载目录，自动创建不存在的接收目录，并在接收页显示完整路径。
- 增强网页下载的断点范围、大文件流式 ZIP 和 Windows 安全文件名处理。
