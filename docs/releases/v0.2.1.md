# LocalShare v0.2.1

应用版本 **0.2.1**，构建号 **63**；Windows 安装版本 **0.2.1.63**。

## 主要更新

- **任务中心**：发送、接收、媒体同步和实际网页下载统一显示进度、速度、已用时间与预计剩余时间。切换页面或关闭详情后继续传输，取消任务单独操作。
- **并发与排队**：默认同时运行 2 个传输任务，设置可调整为 1–8 个；媒体同步最多同时运行 1 个。多个接收请求分别确认、分别管理。
- **暂停与续传**：原生 LocalShare 传输支持暂停、继续和失败重试，保存分块偏移，并进行分块及全文件 SHA-256 校验。任务记录支持手动清理和按时间清理。
- **保留文件结构**：普通接收按任务创建独立目录，保留原文件名及相对目录层级；媒体同步沿用原保存方式。
- **操作优先首页**：导航改为「首页、任务、发送、同步、设置」。首页提供发送、网页传输、媒体同步、接收确认、当前任务与附近设备，网页发送和网页接收入口明确分开。
- **接收与同步改进**：旧接收历史保留，任务详情可打开已完成文件；媒体同步的校验和确认记录不再依赖备份页面；网页分享离开页面后继续运行。
- **项目维护**：保留英文和中文 README，清理失效文件及旧 WinGet 发布任务，保留已合并的 Dependabot Actions 升级。

## 下载

- Android：`LocalShare-0.2.1-android-arm64-v8a.apk`，仅支持 ARM 64 位（arm64-v8a）；最低 Android 5.0。
- Windows：`LocalShare-Setup-0.2.1.63-x64.exe`，x64 安装程序，包含运行所需文件。
- Windows 免安装包：`LocalShare-0.2.1-windows-x64.zip`，解压后运行 `LocalShare.exe`。
- `LocalShare-0.2.1-SHA256SUMS.txt` 与 `LocalShare-0.2.1-build-info.json` 提供文件校验、版本和签名信息。

## 升级与签名

Android 沿用项目固定发布证书，可覆盖本地签名版 0.2.0。旧 GitHub 正式版 0.1.0 / 0.1.1 的 Android 签名不同，**请先备份应用配置与记录，再卸载旧版并安装新版**；已保存的接收文件请妥善保留。后续沿用此证书的版本可覆盖升级。

Windows 沿用同一应用标识和自签名代码签名证书，安装程序支持升级。系统仍可能显示发布者不受信任或 SmartScreen 提示。签名私钥与密码保存在本地，未上传 GitHub。

## 验证与支持范围

发布前 313 项应用测试、5 项续传测试通过，Flutter 静态检查无问题。Windows 与 Android 使用 Release 构建；未进行手机实机安装和长时间传输验收。

字节续传需要双方使用支持新协议的 LocalShare。Android `content://` 系统目录和网页上传目前使用整文件方式；浏览器单文件下载支持 HTTP Range，ZIP 下载不支持续传。当前保证应用运行期间切换页面继续任务，Android 息屏和系统后台保活属于后续阶段。
